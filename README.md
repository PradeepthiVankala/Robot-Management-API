
ROBOT MANAGEMENT REST API

A simple REST API built with Flask for managing various activities.

1. Install Flask

pip install Flask

2. Run the application

py app.py


In the code it was mentioned the block of code consisting of particular activity like 
for Robot Registration, Robot status update, Retreival of details etc..

After running the server with app.py go to

http://localhost:5000


PROJECT STRUCTURE :


Robot Management API/
   app.py              # Main application
   requirements.txt    # Dependencies/Packages
   README.md           # This file


FEATURES:

1. Robot registration with unique IDs
2. Status updates
3. JSON responses
4. Error Handling
5. RESTful API design


REQUIREMENTS:

Python 3.7+
Flask 3.0.0
